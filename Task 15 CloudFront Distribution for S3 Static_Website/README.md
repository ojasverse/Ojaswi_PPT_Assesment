# Task 15: CloudFront Distribution for S3 Static Website

## Objective
To improve website performance using CDN.

## Services Used
- Amazon S3
- CloudFront

## Implementation Steps
1. Created S3 static website.
2. Created CloudFront distribution.
3. Linked S3 bucket as origin.
4. Accessed website via CloudFront domain.
