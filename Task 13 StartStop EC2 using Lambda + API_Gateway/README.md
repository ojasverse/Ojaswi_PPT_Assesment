# Task 13: Start/Stop EC2 using Lambda & API Gateway

## Objective
To automate EC2 start/stop operations using API trigger.

## Services Used
- AWS Lambda
- API Gateway
- EC2
- IAM Role

## Implementation Steps
1. Created IAM role with EC2 permissions.
2. Created Lambda function for start/stop.
3. Integrated Lambda with API Gateway.
4. Deployed API.
5. Triggered API using browser/Postman.
