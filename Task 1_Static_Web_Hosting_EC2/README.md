
# Task 1: Static Web Hosting using EC2 (Ubuntu + Nginx)

## Objective
To deploy a static website on an Ubuntu EC2 instance using Nginx web server.

## Services Used
- AWS EC2
- Ubuntu 22.04
- Nginx

## Implementation Steps
1. Launched Ubuntu EC2 instance.
2. Connected using SSH.
3. Installed Nginx.
4. Initialized git.
5. Cloned one static website.
6. Started and enabled Nginx service.
7. Deployed website files.
8. Accessed website using Public IP.

- Screenshots

## Outcome
Successfully hosted static website on EC2 instance.
