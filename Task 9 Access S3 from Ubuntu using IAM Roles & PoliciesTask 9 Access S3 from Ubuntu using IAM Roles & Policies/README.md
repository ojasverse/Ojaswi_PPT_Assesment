# Task 9: Access S3 using IAM Role

## Objective
To access S3 securely without access keys.

## Steps
1. Created IAM Role with S3 policy.
2. Attached role to EC2.
3. Installed AWS CLI.
4. Tested S3 access.

## Proof
- Role Attached
- AWS CLI Output

## Outcome
Successfully accessed S3 via IAM Role.
