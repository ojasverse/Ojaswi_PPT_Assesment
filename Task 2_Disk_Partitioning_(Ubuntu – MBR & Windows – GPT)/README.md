Task 2: Disk Partitioning (MBR & GPT)

Objective
To understand disk partitioning structure using MBR (Linux) and GPT (Windows).

Tools Used
- Ubuntu (fdisk)
- Windows Disk Management

Implementation Steps

Windows – GPT Partitioning
-Steps:
1. Open Disk Management
2. Right-click unallocated space
3. Select "New Simple Volume."
4. Assign size and drive letter
5. Format with NTFS

Linux – MBR Partitioning (Using fdisk)
1. Checked disk using lsblk.
2. Created partition using fdisk.
3. Formatted partition.
4. Mounting.

Proof
- Screenshots

Outcome
Successfully created and managed MBR and GPT partitions.
