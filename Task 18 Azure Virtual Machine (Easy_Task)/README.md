# Task 18: Azure Virtual Machine

## Objective
To launch and configure a basic Azure Virtual Machine and access it using SSH/RDP.

## Steps Performed
- Logged into Azure Portal.
- Created a Resource Group.
- Created a Virtual Machine (Ubuntu/Windows).
- Selected VM size (B1s or default sandbox size).
- Configured authentication (Username & Password / SSH Key).
- Allowed required inbound ports (SSH/RDP).
- Deployed the VM successfully.
- Verified VM status as "Running".
- Accessed the VM using SSH (Linux) or RDP (Windows).

## Services Used
- Azure Virtual Machine
- Resource Group
- Virtual Network (Auto-created)
- Public IP Address
- Network Security Group

## Verification
- VM Status: Running
- Successfully accessed the VM.
