# Task 11: S3 Upload Email Notification using Lambda & SNS

## Objective
To trigger email notification whenever a file is uploaded to S3 bucket.

## Services Used
- Amazon S3
- AWS Lambda
- SNS (Simple Notification Service)
- IAM Role

## Implementation Steps
1. Created S3 bucket.
2. Created SNS topic and subscribed email.
3. Created Lambda function.
4. Attached IAM role with required permissions.
5. Configured S3 event trigger to Lambda.

## Outcome
Email alert successfully triggered on S3 file upload.
